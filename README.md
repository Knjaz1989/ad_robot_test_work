# ad_robot_test_work

## Запуск

1. Установить зависимости из requirements.txt:

   ```bash
   pip install -r requirements.txt
   ```

2. Накатить зависимости из poetry:

   ```bash
   poetry install
   ```

3. Запустить приложение через модуль `run`:

   ```bash
   python -m app.run
   ```

После запуска приложение будет доступно на `http://127.0.0.1:10500`.
